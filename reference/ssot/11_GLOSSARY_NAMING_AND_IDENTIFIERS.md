# Glossary, Naming, and Identifier Guardrails

- **XtraType** — contextual application/client. Do not rename it to PortaShape.
- **PortaShape** — framework/host/interoperability/data-transport/plugin architecture around applications and modules.
- **Script Studio** — planned PortaShape script-building/editing/testing surface.
- **Stay D.R.Y.** — planned reusable text/pattern assistance plugin direction with consent boundaries.
- **Universal Publisher / Bridges** — planned publishing core; external provider connectors remain separate packages.
- **Anchor** — structured attachment target. Current built-ins: URL, Time, YouTube, GPS; custom anchors are bounded inert schemas.
- **Annotation** — current contextual record; `Context.Annotation` v2 remains a compatibility anchor.
- **Snapshot** — captured page image/history record; `Revision.Snapshot` v1 remains a compatibility anchor.
- **Young** — current seven-day age signal. Reading does not clear it; explicit Mark all as old does.
- **Current docs** — mutable/current forward reference/status/pointer set defined by `08_VERSIONING_AND_CURRENT_DOCS_SIGNAL.md`, not every recently modified file.
- **Landmark** — immutable versioned/timestamped historical truth.
- **Legacy / perpetual legacy** — preserved foundational authority for its scope; not “discardable old stuff.”
- **Target** — specified desired behavior, not evidence of implementation.
- **Technical version** — platform-valid Chrome/npm/server identifier, currently inherited `2.5.0` in source.
- **Canonical project version** — project-development line, currently **v.002**.
- **XT Group Chat code** — current five-character case-sensitive access identifier used in `xtratype.com/gc/#####` conventions.

When adding a major new term, update this glossary and the current decision/specification references if semantics matter across subsystems.
